# 로컬 여행 블로그 봇 1.0

기존 뉴스 블로그 봇과 **별개로 실행하는** Streamlit 앱입니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

앱 왼쪽 사이드바에서 OpenAI API 키를 입력하거나, Streamlit Cloud 앱 설정 > Secrets에 아래처럼 등록합니다.

```toml
OPENAI_API_KEY = "실제_키"
OPENAI_MODEL = "gpt-6-astra"
```

모델은 OpenAI API 계정에서 Responses API 및 web_search를 사용할 수 있는 모델이어야 합니다. 오류가 발생하면 사용 가능한 모델로 수정하세요. **ChatGPT 구독 비용과 API 요금은 별도입니다.**

## 주요 기능

1. 지역, 독자 연령, 일정, 예산 및 콘텐츠 범위 선택
2. OpenAI Responses API 웹 검색으로 숨은 관광지와 실제 식당·카페·상점·숙소 조사
3. 유사 검색 결과 분석 및 제목 후보 10개 작성
4. 제목을 사용자가 선택/수정한 뒤 본문 생성
5. Markdown/HTML로 저장

## 제한사항

- 검색결과 노출과 실제 검색량, SEO 성과는 다릅니다. 연령별 정확한 검색 순위는 API에서 자동 제공되지 않습니다.
- 웹 검색 결과의 운영시간·상호·숙소·가격·역사 이야기는 발행 전에 직접 확인해야 합니다.
- 주변 이동시간, 매장 예약 가능 여부, 실제 숙박요금은 자동 검증하지 않습니다.
- 네이버·구글 블로그 자동발행, 실제 노출 성과 분석은 미구현입니다.
- 사이트나 매장 정보를 지어내지 않도록 지시하지만 생성형 AI 특성상 오류가 발생할 수 있습니다.
- 뉴스 블로그 봇 파일은 건드리지 않습니다.
